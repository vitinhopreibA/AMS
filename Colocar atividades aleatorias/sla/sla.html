HTML

1. O que é HTML?

É a linguagem usada para estruturar páginas web.

2. O que são tags?

São elementos que definem a estrutura do conteúdo.

3. Para que serve a tag <a>?

Cria links para páginas ou seções.

4. Como inserir imagens?

Utilizando a tag <img>.

5. O que é uma âncora?

Um link que leva para uma parte específica da página.
